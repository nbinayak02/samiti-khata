## [1.0.1] - 2026-04-18

### Changed

- Bill Issuer is optional in Add Income
- Amount can be greater or equal to 0

## [1.0.0] - 2026-04-18

### Added

- User signup and login
- Role based access to resources
- Admin approval for operator
- Create Committee, Bill Issuers, Categories
- Add Incomes and Expenses
